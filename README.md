# Método de Gauss - Sistema de Ecuaciones Lineales

Programa desarrollado en **Java** bajo un diseño modular que implementa el **Método de Gauss** con pivoteo parcial para resolver sistemas de ecuaciones lineales.

## 📂 Estructura Modular
- **`Main.java`**: Clase principal que coordina el flujo de ejecución.
- **`LectorDatos.java`**: Módulo encargado de la lectura de la matriz aumentada y la presentación en consola.
- **`MetodoGauss.java`**: Módulo que contiene la lógica matemática de resolución.

---

## ⚙️ Instrucciones para Compilar y Ejecutar

1. Abre una terminal en la carpeta contenedora de los archivos fuente `.java`.
2. Compila los archivos ejecutando:
   ```bash
   javac Main.java LectorDatos.java MetodoGauss.java
